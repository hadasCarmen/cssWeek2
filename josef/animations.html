Part 1: CSS Animations

CSS animations allow you to create complex motion sequences using keyframes.

1.1 Basic Animation Syntax

Animations consist of two parts: the @keyframes rule and the animation property.

@keyframes animationName { 0% { transform: translateY(0); } 100% { transform: translateY(-30px); } } .element { animation: animationName 1s infinite; }

1.2 Bounce Animation

Bounce
@keyframes bounce { 0%, 100% { transform: translateY(0); } 50% { transform: translateY(-30px); } }

1.3 Spin Animation

Spin
@keyframes spin { from { transform: rotate(0deg); } to { transform: rotate(360deg); } }

1.4 Pulse Animation

Pulse
@keyframes pulse { 0%, 100% { transform: scale(1); opacity: 1; } 50% { transform: scale(1.1); opacity: 0.8; } }

1.5 Slide In Animation

Slide
@keyframes slideIn { from { transform: translateX(-100%); opacity: 0; } to { transform: translateX(0); opacity: 1; } }

1.7 Shake Animation (Hover)

Shake
@keyframes shake { 0%, 100% { transform: translateX(0); } 10%, 30%, 50%, 70%, 90% { transform: translateX(-10px); } 20%, 40%, 60%, 80% { transform: translateX(10px); } }

1.8 Complex Animation

Multiple properties can be animated simultaneously across different keyframes.

Complex
@keyframes complex { 0% { transform: translate(0, 0) rotate(0deg) scale(1); } 25% { transform: translate(50px, -30px) rotate(90deg) scale(1.2); } 50% { transform: translate(100px, 0) rotate(180deg) scale(0.8); } 75% { transform: translate(50px, 30px) rotate(270deg) scale(1.2); } 100% { transform: translate(0, 0) rotate(360deg) scale(1); } }
Tip: Use animation timing functions like ease, ease-in, ease-out, ease-in-out, or linear to control the speed curve.

Part 2: Animation Properties

2.1 Animation Properties Breakdown

  • animation-name: The name of the @keyframes animation
  • animation-duration: How long the animation takes (e.g., 2s, 500ms)
  • animation-timing-function: The speed curve (ease, linear, ease-in-out, etc.)
  • animation-delay: Time to wait before starting (e.g., 1s)
  • animation-iteration-count: Number of times to repeat (number or infinite)
  • animation-direction: normal, reverse, alternate, alternate-reverse
  • animation-fill-mode: How styles apply before/after animation (forwards, backwards, both)
  • animation-play-state: running or paused
/* Shorthand syntax */ animation: name duration timing-function delay iteration-count direction fill-mode; /* Example */ animation: bounce 2s ease-in-out 0.5s infinite alternate;

2.2 Timing Functions

  • linear: Constant speed from start to end
  • ease: Slow start, fast middle, slow end (default)
  • ease-in: Slow start, then speeds up
  • ease-out: Fast start, then slows down
  • ease-in-out: Slow start and end
  • cubic-bezier(n,n,n,n): Custom timing function

Part 3: Best Practices

Performance Tips

  • Prefer transform and opacity for animations (hardware accelerated)
  • Avoid animating properties like width, height, or margin
  • Use will-change property for complex animations
  • Keep animations under 200-300ms for UI interactions
  • Use requestAnimationFrame for JavaScript animations

Accessibility Considerations

  • Respect prefers-reduced-motion media query for users sensitive to motion
  • Don't rely solely on animation to convey information
  • Avoid animations that flash more than 3 times per second
  • Provide alternative ways to access animated content
/* Respect user preferences */ @media (prefers-reduced-motion: reduce) { * { animation-duration: 0.01ms !important; animation-iteration-count: 1 !important; transition-duration: 0.01ms !important; } }
